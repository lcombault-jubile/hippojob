Vers Sheets : bouton « ☁️ Copier pour Sheet » dans le tableau de suivi, puis Ctrl+V dans la cellule A1.

Sauvegarde quotidienne : préfère « 💾 Sauvegarder (JSON) », fidèle à 100 % (Sheets reformate les dates).
